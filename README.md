# Безопасный маршрут

Мобильная веб-версия интерактивного тренажёра цифровой безопасности по ИАР Помарковой Л. В.: 10 модулей, 5 возрастных маршрутов, два героя и локальная озвучка Silero.

Открыть игру: https://lidmara74.github.io/bezopasnyy-marshrut/

Прогресс сохраняется в браузере устройства. Перенос между устройствами доступен через экспорт и импорт в настройках игры.
